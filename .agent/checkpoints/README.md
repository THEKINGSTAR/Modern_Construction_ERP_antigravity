# Checkpoints

This directory and the root `CHECKPOINTS.md` track the known verified completion of engineering stages.

## Usage
- Each major functional group corresponds to a Stage.
- When a Stage is verified as complete and golden paths are working, a Git tag should be created (e.g., `stage-18`) and `CHECKPOINTS.md` must be updated.
- These checkpoints form the basis for `recovery/known-good.md`.
